# Proyecto integrador: Finanzas personales

## Desafío

Construye una solución demostrable que aplique los aprendizajes de las 14 clases de esta parte.

## Requisitos mínimos

- Problema y usuario definidos.
- Datos ficticios o anonimizados.
- Supuestos explícitos.
- Cálculos reproducibles.
- Riesgos y limitaciones.
- Evidencia de pruebas.
- Presentación ejecutiva de cinco minutos.

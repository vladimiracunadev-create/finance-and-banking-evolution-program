# Proyectos

Cada parte termina con un proyecto. Los proyectos forman un portafolio progresivo y alimentan el Banco Virtual.

| Proyecto | Resultado |
|---|---|
| Calculadora financiera | Motor de interés y valor del dinero |
| Plan financiero anual | Presupuesto, flujo y patrimonio |
| Comparador de productos | Evaluación de costo y condiciones |
| Protocolo de seguridad | Prevención y respuesta |
| Estados financieros | Reportes y análisis |
| Informe macrofinanciero | Escenarios económicos |
| Motor de valoración | VAN, TIR y sensibilidad |
| Cartera simulada | Portafolio y rebalanceo |
| Scoring de crédito | Decisión explicable |
| Sucursal virtual | Cuentas y operaciones |
| Tablero de riesgos | Indicadores y límites |
| Sistema de cumplimiento | KYC, alertas y evidencias |
| Propuesta empresarial | Comité de crédito |
| Plataforma fintech | APIs, datos e IA |
| Plan estratégico | Dirección bancaria |
| Banco virtual | Integración total |

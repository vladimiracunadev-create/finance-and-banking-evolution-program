# Contribuir

1. Crea una rama por cambio.
2. Mantén el lenguaje claro y educativo.
3. No presentes datos sintéticos como reales.
4. Cita fuentes primarias cuando se agregue normativa.
5. Añade pruebas para cualquier cálculo financiero.
6. Ejecuta `python tools/validate_program.py` y `pytest`.
7. Para JavaScript o TypeScript, usa `pnpm`; no agregues `npm` como gestor principal.

## Convención de clases

Cada clase debe incluir objetivos, prerrequisitos, conceptos, agenda de 90 minutos, actividad, laboratorio, evaluación y entregable.

# Edición Chile — plantilla

Esta carpeta está preparada para una futura adaptación chilena.

## Contenido pendiente de validación oficial

- Autoridades e instituciones vigentes.
- Derechos del consumidor financiero.
- Tasas, indicadores y costos de referencia.
- Protección de datos y ciberseguridad.
- Prevención de lavado de activos.
- Normas contables y prudenciales aplicables.
- Tributación de inversiones y productos.

Toda ficha deberá registrar:

- fuente oficial;
- URL de origen;
- fecha de consulta;
- fecha de vigencia;
- responsable de revisión;
- alcance y limitaciones.

No se incorporan reglas concretas en esta versión para evitar presentar normativa desactualizada como vigente.

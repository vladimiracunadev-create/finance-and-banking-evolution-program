# Fórmulas esenciales

## Interés simple

`VF = VP × (1 + i × n)`

## Interés compuesto

`VF = VP × (1 + i)^n`

## Valor presente

`VP = VF / (1 + i)^n`

## Cuota fija

`Cuota = P × [r(1+r)^n] / [(1+r)^n - 1]`

## Valor actual neto

`VAN = Σ FC_t / (1+k)^t - Inversión inicial`

> Convierte siempre la tasa a la misma periodicidad de los flujos.

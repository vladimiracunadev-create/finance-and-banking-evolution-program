# Ética y limitaciones

- Ningún simulador entrega recomendaciones de inversión personalizadas.
- Los modelos de scoring educativos no deben decidir créditos reales.
- No uses atributos sensibles para discriminar.
- Toda decisión automatizada debe ser explicable, revisable y documentada.
- Las tasas, impuestos y reglas cambian; valida vigencia antes de actuar.

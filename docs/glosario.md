# Glosario inicial

- **Activo:** recurso controlado con beneficio económico esperado.
- **Pasivo:** obligación presente.
- **Patrimonio:** diferencia entre activos y pasivos.
- **Liquidez:** capacidad de cumplir obligaciones oportunamente.
- **Solvencia:** capacidad estructural de responder por obligaciones.
- **Interés:** precio del dinero en el tiempo.
- **Amortización:** reducción gradual de una deuda.
- **Riesgo de crédito:** posibilidad de incumplimiento.
- **Scoring:** estimación estructurada del riesgo de un solicitante.
- **KYC:** proceso de conocimiento e identificación del cliente.
- **Fintech:** aplicación de tecnología a servicios financieros.
- **Open banking:** intercambio autorizado de datos y servicios mediante interfaces seguras.

# Fichas de conjuntos de datos

Una ficha por conjunto. Cada una declara nombre, ruta, origen, licencia, fecha,
metodo de generacion, diccionario de columnas, supuestos, calidad y limites.

La linea «NO significa» de cada columna no es un adorno: evita la mitad de los
errores de integracion, que nacen de dos personas entendiendo distinto el mismo
campo.

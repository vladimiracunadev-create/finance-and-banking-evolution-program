# Datasets

Todos los datasets incluidos son **sintéticos** y sirven únicamente para aprendizaje.

- `personal_budget_synthetic.csv`: presupuesto anual.
- `loan_applications_synthetic.csv`: solicitudes de crédito ficticias.
- `transactions_synthetic.csv`: transacciones con anomalías artificiales.

No representan personas, bancos, tasas ni comportamientos reales.
